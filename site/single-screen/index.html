Use the same companions

Import an existing companion ZIP or create one for a supported ROM inside the emulator. The browser GBA Duo Companion Builder also works with Plus SS.

Plus and Plus SS install side by side. Each app has its own private saves, companion packs and settings.

Get started with Plus SS

  1. Install the SS APK

    Download the Single Screen edition above. Android may ask you to allow installation from your browser.

  2. Add your game folder

    Open Settings, add your ROM folder and select a game. GBA, GB and GBC are supported by the emulator.

  3. Create or import a companion

    For an exact supported ROM, choose “Find and create companion”, or import a Local ZIP generated by the Companion Builder.

Large ZIP files can take time to open. Loading feedback and Menu cancellation are available. See device validation and current limits.

Using a dual-screen handheld?
