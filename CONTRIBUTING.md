# Contributing

Please start with [UPSTREAM](docs/UPSTREAM.md), [BUILDING](docs/BUILDING.md), [CREDITS](CREDITS.md) and the pinned-baseline feature comparison. Preserve original authorship and third-party headers. Contributions must remain compatible with the application's GPL v3 terms and the component licenses.

Keep pull requests focused and describe the user-visible change, inherited behavior, validation and remaining device limitations in English. Add a regression test for behavior changes. Do not claim that host tests establish live achievement awards or GPU/device compatibility.

Do not add ROMs/BIOS dumps, private companion assets, personal captures, credentials, keystores, generated build trees or local SDK paths. Use synthetic fixtures. Do not reintroduce hash-identity overrides or translation experiments into this Plus edition without an explicit project scope decision.

Reproduce Plus-specific issues against the documented baseline before reporting them upstream. Changes to native libraries/shaders must retain source/license provenance and a reproducible pinned revision.
